# PM templates

Copy only the shape the work needs. Replace placeholders and keep status/acceptance truthful.

- [Campaign Checklist](<Campaign Checklist.md>) — the only checkbox queue.
- [Campaign Master Book](<Campaign Master Book.md>) — purpose, state/evidence, decisions, criteria and shipped receipts.
- [Supporting Document](<Supporting Document.md>) — an accepted cross-module plan or a bounded research source; no independent backlog.
- [Item Execution Plan](<Item Execution Plan.md>) — a compact KIT-11-style plan inside one existing item; readiness, steps and verification without another queue.

Follow [_Conventions](<../_Conventions.md>). A new campaign is justified by durable ownership, not by the size of an audit. Existing modules normally use their current campaign.
